# Mini CRM - Client Lead Management System

This is a simple Client Lead Management System built as part of the internship assignment. It helps to manage customer leads generated from website contact forms.

## Features
- Lead listing with Name, Email, Source, and Status.
- Ability to update lead status (New, Contacted, Converted).
- Add notes and follow-ups for each lead.

## Tech Stack
- Frontend: HTML5, CSS3, JavaScript
- Backend: Node.js / Express.js (Optional / Planned)
- Database: MongoDB / MySQL (Optional / Planned)
